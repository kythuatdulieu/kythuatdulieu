### 🏗️ Các Dự Án Thực Chiến (E2E Practice Repos)
Chúng tôi tổng hợp và xây dựng các dự án End-to-End từ cộng đồng để mô phỏng môi trường làm việc thực tế. Toàn bộ kiến trúc đều được phân tích bằng tiếng Việt trên Website.

- [**EcomLake**](https://github.com/kythuatdulieu/EcomLake) — Hệ thống Data Lakehouse cho E-commerce sử dụng **Spark, Dagster, MinIO** và Streamlit. [(Đọc phân tích)](https://kythuatdulieu.github.io/projects/e2e/ecomlake/)
- [**snowflakedemo**](https://github.com/kythuatdulieu/snowflakedemo) — Mô phỏng luồng dữ liệu tài chính với **Snowflake, Snowpipe**, Event-driven Ingestion và Data Quality (DMFs). [(Đọc phân tích)](https://kythuatdulieu.github.io/projects/e2e/snowflakedemo/)
- [**FMD_FRAMEWORK**](https://github.com/kythuatdulieu/FMD_FRAMEWORK) — Giải pháp tự động hóa Data Pipeline bằng siêu dữ liệu (Metadata-Driven) trên nền tảng **Microsoft Fabric**. [(Đọc phân tích)](https://kythuatdulieu.github.io/projects/e2e/fabric-metadata-framework/)
- [**movie-analytics-pipeline**](https://github.com/kythuatdulieu/movie-analytics-pipeline) — Data Stack hoàn toàn chạy trên Local sử dụng **DuckDB, dbt, Apache Airflow và Superset**. [(Đọc phân tích)](https://kythuatdulieu.github.io/projects/e2e/movie-analytics-pipeline/)
